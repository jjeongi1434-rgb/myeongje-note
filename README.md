# 명제 탐구 노트

**학생용 주소: https://jjeongi1434-rgb.github.io/myeongje-note/**

고등학교 수학 「집합과 명제 – 명제」 단원 학습용 웹앱입니다. 학생이 **직접 만든 문장**으로 단원 전체를 탐구하고, 활동 내용을 기록해 보고서로 출력합니다. 서버·AI API 없이 **`index.html` 파일 하나**로 동작하며 비용이 들지 않습니다.

## 차시별 구성 (10차시)

| 차시 | 주제 · 학습 목표 | 화면 | 바탕 자료 |
|---|---|---|---|
| 1 | **명제와 조건** — 명제와 조건의 뜻을 알고, 내가 만든 문장의 참·거짓을 근거를 들어 판별한다 | 1 문장 만들기 → 2 유형 ① 명제·조건 판별 → 3 참/거짓 판별 + 판별 기준 → 4 유형 ② 참·거짓 | 학습지 1쪽 ①②, 유형 문제 |
| 2 | **명제의 부정과 진리집합** — 부정을 만들어 참·거짓을 판별하고, 조건과 그 부정의 진리집합을 구한다 | 5 부정문 → 6 유형 ③ 부정 → 7 진리집합 → 8 유형 ④ 진리집합 | 학습지 1쪽 ③, 2쪽 진리집합, 교과서 80~81쪽 |
| 3 | **‘모든’·‘어떤’과 명제 정리** — ‘모든’·‘어떤’ 명제의 참·거짓과 부정(그리고/또는 포함)을 진리집합으로 설명하고 정리표를 완성한다 | 9 ‘모든’·‘어떤’ → 10 유형 ⑤ → 11 개념 확인 빈칸 + 정리표("Ⅰ부 기록 가져오기") | 학습지 1쪽 ④⑤, 2쪽, 교과서 81~83쪽 |
| 4 | **유형 문제 오답 정리** — 1~5단계에서 푼 유형 문제를 돌아보고 유형별로 틀린 이유를 정리한다 | 12 유형 ①~⑤ 풀이 현황표 + 유형별 오답 정리 + 나의 체크리스트 | 학습지 유형 1~3, 총정리 |
| 5 | **명제 p → q** — 가정·결론, 진리집합 포함 관계, 반례 | 13 개념정리 ① 빈칸 → 내 명제 탐구 → 14 유형 ⑥ | 학습지 개념정리 1, 교과서 84~85쪽 |
| 6 | **명제의 역과 대우** — 역·대우 만들기, 명제와 대우의 참·거짓 일치 | 15 개념정리 ② → 16 유형 ⑦ | 학습지 개념정리 2, 교과서 86~87쪽 |
| 7 | **충분조건과 필요조건** — 진리집합의 포함 관계로 판단 | 17 개념정리 ③ → 18 유형 ⑧ | 학습지 개념정리 3, 교과서 87~88쪽 |
| 8 | **명제의 증명** — 정의·정리, 대우 이용 증명, 귀류법 | 19 증명 | 교과서 89~91쪽 |
| 9 | **절대부등식** — 뜻, 증명, 등호 성립 조건 | 20 절대부등식 | 교과서 92~93쪽 |
| 10 | **마무리와 활동 기록** — 성찰·자기평가, 활동 기록 제출 | 21 성찰 → 활동 기록 인쇄/Word | |

- 홈 화면에 차시별 학습 계획표가 있고, 각 차시의 첫 화면에 학습 목표가 표시됩니다. 왼쪽 메뉴도 차시별로 묶여 있습니다.
- 활동 기록(보고서)과 Word 파일은 차시 제목 → 단계 순으로 정리됩니다. 교사용 취합 표에는 학생별 완료 차시 수가 나옵니다.
- 차시 배분·제목·학습 목표는 `index.html`의 `LESSONS` 배열에서 바꿀 수 있습니다.

탐구 단계는 챗봇 지침의 흐름대로 **초안 쓰기 → 판정 기준·자동 힌트 → 체크리스트 → 고쳐 쓰기·성찰 → 연습문제** 순서이고, 정답은 초안을 제출한 뒤에만 볼 수 있습니다. 모든 입력란은 필수입니다. **유형 문제는 각 내용 단계 바로 뒤의 독립 화면**이며, 모든 문항을 풀고 채점해야 다음으로 넘어갈 수 있습니다.

교과서 문제 세트(본문 문제·중단원 마무리·대단원 평가·협력 활동)는 **교사 모드**에서만 각 단계 끝에 표시됩니다.

## 제출 수집 설정 (학생 기록을 구글 시트로 모으기) — 한 번만 설정

핸드폰(특히 카카오톡·네이버 앱 안의 브라우저)에서는 파일 다운로드가 막히는 경우가 많습니다. 그래서 학생이 **📤 제출** 버튼을 누르면 기록이 선생님의 **구글 시트**로 바로 들어가도록 만들었습니다. 무료이고, 선생님 구글 계정만 있으면 됩니다.

1. 구글 드라이브에서 **새 스프레드시트**를 만듭니다 (이름 예: `명제 탐구 노트 제출함`).
2. 시트 메뉴 **확장 프로그램 → Apps Script** 를 엽니다. 기본으로 있는 코드를 지우고, 이 폴더의 [`apps-script.gs`](apps-script.gs) 내용을 전부 붙여넣습니다.
3. 코드 맨 위 `const KEY = '명제교사';` 를 원하는 교사 코드로 바꿉니다 (앱의 교사 모드 코드와 같게 두면 편합니다). 저장(💾).
4. 오른쪽 위 **배포 → 새 배포** → 유형 선택(⚙️)에서 **웹 앱** → 설명 아무거나 → **실행 사용자: 나** → **액세스 권한: 모든 사용자** → 배포. 처음엔 "액세스 승인" 창이 뜨는데, 본인 계정 선택 → 고급 → "(프로젝트 이름)(으)로 이동" → 허용.
5. 표시되는 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사합니다.
6. `index.html`에서 `const SUBMIT_URL='';` 의 따옴표 안에 그 URL을 붙여넣고 GitHub에 올립니다. (GitHub 사이트에서 index.html → 연필 아이콘 → 수정 → Commit changes 로도 됩니다.) 1~2분 뒤 학생 화면에 반영됩니다.

이후 흐름:
- 학생: 홈에서 학번(학년·반·번호 포함, 예 10315)·이름·**제출 비밀번호(숫자 4자리)** 입력 → 활동 → 상단 **📤 제출** (수업이 끊길 때마다). 여러 번 제출해도 학생별 **최신 것**만 취합됩니다. 이름 등을 안 넣고 제출을 누르면 그 자리에서 물어봅니다.
- 학생(다른 기기·기록이 지워졌을 때): 홈 → **📥 내 기록 불러오기** → 학번·이름·비밀번호 → 마지막 제출 기록을 그대로 이어서 합니다.
- 교사: 앱의 **교사용 취합 → 📥 제출함에서 불러오기** → 코드 입력 → 학생 목록·완료 차시·보고서 일괄 인쇄·CSV. 구글 시트를 직접 열어도 제출 시각·학급·학번·이름·완료 단계가 한 줄씩 쌓여 있습니다.
- `apps-script.gs`가 바뀌면(예: 이 저장소가 업데이트됐을 때) Apps Script 편집기에 새 코드를 붙여넣고 **배포 → 배포 관리 → ✏️ 편집 → 버전: 새 버전 → 배포** 를 해야 반영됩니다. URL은 그대로입니다.

설정 전에는 제출 버튼이 "제출 주소가 설정되지 않았어요"라고 안내하고, 파일 저장 방식(💾 저장)은 계속 쓸 수 있습니다. 핸드폰에서 💾 저장은 공유 시트(파일에 저장 / 카카오톡으로 보내기)로 열립니다.

## 교사 모드 (교과서 문제 보기)

교과서 문제 카드는 저작권을 고려해 학생 화면에는 나오지 않고, 교사 모드에서만 각 단계 끝에 표시됩니다.

- 켜기: 왼쪽 메뉴 **교사용 취합 → 교사 모드 켜기** → 코드 입력 (기본 코드 `명제교사`), 또는 주소 뒤에 `?teacher=명제교사` 를 붙여 접속
- 교사 모드에서는 **학생 정보를 입력하지 않아도** 모든 단계를 둘러볼 수 있고, 각 단계의 **“기준 미리 보기”** 버튼으로 초안 작성 없이 판정 기준·힌트·모범 답안을 바로 볼 수 있습니다
- 끄기: 같은 화면의 **교사 모드 끄기**, 또는 `?teacher=off`
- 코드는 `index.html` 안의 `TEACHER_CODE` 값을 바꾸면 됩니다. (브라우저별로 저장되므로 수업용 PC에서 한 번만 켜면 유지됩니다. 단, 소스에 코드가 들어 있으므로 강한 보안 장치는 아닙니다.)

## 기능

- 브라우저 자동 저장 (localStorage) — 같은 기기·브라우저에서 이어서 작업
- **저장 / 불러오기** — JSON 파일로 내려받아 다른 기기에서 이어서 작업, 교사 제출용
- **활동 기록** — 인쇄 / PDF 저장, Word(.docx) 다운로드, 텍스트(.txt)
- **교사용 취합** — 학생 JSON 파일을 여러 개 올려 진행 상황 표, 보고서 일괄 인쇄, CSV
- 수학 기호 팔레트 (≥ ≤ ≠ ² √ ¬ → ⇒ ⇔ ∀ ∃ ∈ ⊂ ∪ ∩ ∅ …)
- 규칙 기반 자동 점검 힌트 (예: p와 ¬p를 둘 다 참이라고 했을 때, 원명제와 대우의 참·거짓이 다를 때, 부등호를 부정하지 않았을 때 등)

## 배포 방법 (무료)

**방법 1 – 주소로 배포 (권장)**: 교실에 인터넷이 되므로 아래 GitHub Pages나 Netlify Drop에 올리고 주소(QR)를 학생에게 공유하면 됩니다. 모든 학생이 같은 주소를 쓰되 기록은 각자 브라우저에 저장됩니다.

**방법 1-2 – 파일 그대로 전달**: `index.html`을 학급 게시판·메신저로 보내면 학생이 더블클릭해서 바로 사용할 수도 있습니다.

**방법 2 – GitHub Pages**: 저장소를 만들고 `index.html`을 올린 뒤 Settings → Pages → Branch: main 을 선택하면 `https://<아이디>.github.io/<저장소>/` 주소가 생깁니다.

**방법 3 – Netlify Drop**: https://app.netlify.com/drop 에 이 폴더를 끌어다 놓으면 즉시 주소가 생깁니다.

## 수업 운영 팁

- 학생은 차시가 끝날 때마다 **📤 제출**을 누르게 하면(최신 제출만 남음) 교사용 취합에서 한꺼번에 볼 수 있고, 평가 자료가 필요하면 취합 화면에서 보고서를 일괄 인쇄하거나 Word로 받으면 됩니다.
- 단계별 자동 힌트는 형식만 점검합니다. 내용 피드백은 정리표와 보고서를 보며 교사가 제공하는 것을 전제로 설계했습니다.
- 문항·문구 수정은 `index.html` 안의 `STEPS` 배열(각 단계의 `intro`, `draft`, `reveal`, `checklist`, `practice`, `quiz`)만 고치면 됩니다.
