## 교사 모드 (교과서 문제 보기)

교과서 문제 카드는 저작권을 고려해 학생 화면에는 나오지 않고, 교사 모드에서만 각 단계 끝에 표시됩니다.

- 켜기: 왼쪽 메뉴 **교사용 취합 → 교사 모드 켜기** → 코드 입력 (기본 코드 `명제교사`), 또는 주소 뒤에 `?teacher=명제교사` 를 붙여 접속
- 끄기: 같은 화면의 **교사 모드 끄기**, 또는 `?teacher=off`
- 코드는 `index.html` 안의 `TEACHER_CODE` 값을 바꾸면 됩니다. (브라우저별로 저장되므로 수업용 PC에서 한 번만 켜면 유지됩니다. 단, 소스에 코드가 들어 있으므로 강한 보안 장치는 아닙니다.)

## 기능

- 브라우저 자동 저장 (localStorage) — 같은 기기·브라우저에서 이어서 작업
- **저장 / 불러오기** — JSON 파일로 내려받아 다른 기기에서 이어서 작업, 교사 제출용
- **활동 기록** — 인쇄 / PDF 저장, Word(.docx) 다운로드, 텍스트(.txt)
- **교사용 취합** — 학생 JSON 파일을 여러 개 올려 진행 상황 표, 보고서 일괄 인쇄, CSV
- 수학 기호 팔레트 (≥ ≤ ≠ ² √ ¬ → ⇒ ⇔ ∀ ∃ ∈ ⊂ ∪ ∩ ∅ …)
- 규칙 기반 자동 점검 힌트 (예: p와 ¬p를 둘 다 참이라고 했을 때, 원명제와 대우의 참·거짓이 다를 때, 부등호를 부정하지 않았을 때 등)

## 배포 방법 (무료)

**방법 1 – 주소로 배포 (권장)**: 교실에 인터넷이 되므로 아래 GitHub Pages나 Netlify Drop에 올리고 주소(QR)를 학생에게 공유하면 됩니다. 모든 학생이 같은 주소를 쓰되 기록은 각자 브라우저에 저장됩니다.

**방법 1-2 – 파일 그대로 전달**: `index.html`을 학급 게시판·메신저로 보내면 학생이 더블클릭해서 바로 사용할 수도 있습니다.

**방법 2 – GitHub Pages**: 저장소를 만들고 `index.html`을 올린 뒤 Settings → Pages → Branch: main 을 선택하면 `https://<아이디>.github.io/<저장소>/` 주소가 생깁니다.

**방법 3 – Netlify Drop**: https://app.netlify.com/drop 에 이 폴더를 끌어다 놓으면 즉시 주소가 생깁니다.

## 수업 운영 팁

- 학생은 마지막에 **저장(JSON)** 과 **Word 또는 PDF** 두 가지를 제출하게 하면, JSON은 교사용 취합 화면에서 한꺼번에 볼 수 있고 문서는 평가 자료로 보관할 수 있습니다.
- 단계별 자동 힌트는 형식만 점검합니다. 내용 피드백은 정리표와 보고서를 보며 교사가 제공하는 것을 전제로 설계했습니다.
- 문항·문구 수정은 `index.html` 안의 `STEPS` 배열(각 단계의 `intro`, `draft`, `reveal`, `checklist`, `practice`, `quiz`)만 고치면 됩니다.
