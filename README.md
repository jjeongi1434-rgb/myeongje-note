# 명제 탐구 노트

**학생용 주소: https://jjeongi1434-rgb.github.io/myeongje-note/**

고등학교 수학 「집합과 명제 – 명제」 단원 학습용 웹앱입니다. 학생이 **직접 만든 문장**으로 단원 전체를 탐구하고, 활동 내용을 기록해 보고서로 출력합니다. 서버·AI API 없이 **`index.html` 파일 하나**로 동작하며 비용이 들지 않습니다.

## 차시별 구성 (10차시)

| 차시 | 주제 · 학습 목표 | 화면 | 바탕 자료 |
|---|---|---|---|
| 1 | **명제와 조건** — 명제와 조건의 뜻을 알고, 내가 만든 문장의 참·거짓을 근거를 들어 판별한다 | 1 문장 만들기(명제/조건/명제 아님) + 유형 ① · 2 참/거짓 판별 + 나만의 판별 기준 + 유형 ② | 학습지 1쪽 ①②, 유형 문제 |
| 2 | **명제의 부정과 ‘모든’·‘어떤’** — 부정을 만들고, ‘모든’·‘어떤’ 명제의 참·거짓과 부정을 설명한다 | 3 부정문 + 유형 ③ · 4 ‘모든’·‘어떤’ (그리고/또는의 부정 포함) + 유형 ④ | 학습지 1쪽 ③④⑤, 유형 문제 |
| 3 | **진리집합과 명제 정리** — 진리집합을 구하고 탐구 내용을 정리표로 정리한다 | 5 진리집합 + 유형 ⑤ · 6 개념 확인 빈칸 + 정리표("Ⅰ부 기록 가져오기") | 학습지 2쪽, 챗봇 지침 5단계, 교과서 79~83쪽 |
| 4 | **유형 문제 오답 정리** — 1~5단계에서 푼 유형 문제를 돌아보고 유형별로 틀린 이유를 정리한다 | 7 유형 ①~⑤ 풀이 현황표 + 유형별 오답 정리 + 나의 체크리스트 | 학습지 유형 1~3, 총정리 |
| 5 | **명제 p → q** — 가정·결론, 진리집합 포함 관계, 반례 | 8 개념정리 ① 빈칸 → 내 명제 → 문제 | 학습지 개념정리 1, 교과서 84~85쪽 |
| 6 | **명제의 역과 대우** — 역·대우 만들기, 명제와 대우의 참·거짓 일치 | 9 개념정리 ② | 학습지 개념정리 2, 교과서 86~87쪽 |
| 7 | **충분조건과 필요조건** — 진리집합의 포함 관계로 판단 | 10 개념정리 ③ | 학습지 개념정리 3, 교과서 87~88쪽 |
| 8 | **명제의 증명** — 정의·정리, 대우 이용 증명, 귀류법 | 11 증명 | 교과서 89~91쪽 |
| 9 | **절대부등식** — 뜻, 증명, 등호 성립 조건 | 12 절대부등식 | 교과서 92~93쪽 |
| 10 | **마무리와 활동 기록** — 성찰·자기평가, 활동 기록 제출 | 13 성찰 → 활동 기록 인쇄/Word | |

- 홈 화면에 차시별 학습 계획표가 있고, 각 차시의 첫 화면에 학습 목표가 표시됩니다. 왼쪽 메뉴도 차시별로 묶여 있습니다.
- 활동 기록(보고서)과 Word 파일은 차시 제목 → 단계 순으로 정리됩니다. 교사용 취합 표에는 학생별 완료 차시 수가 나옵니다.
- 차시 배분·제목·학습 목표는 `index.html`의 `LESSONS` 배열에서 바꿀 수 있습니다.

탐구 단계는 챗봇 지침의 흐름대로 **초안 쓰기 → 판정 기준·자동 힌트 → 체크리스트 → 고쳐 쓰기·성찰 → 연습문제** 순서이고, 정답은 초안을 제출한 뒤에만 볼 수 있습니다. 모든 입력란은 필수입니다.

교과서 문제 세트(본문 문제·중단원 마무리·대단원 평가·협력 활동)는 **교사 모드**에서만 각 단계 끝에 표시됩니다.

## 교사 모드 (교과서 문제 보기)

교과서 문제 카드는 저작권을 고려해 학생 화면에는 나오지 않고, 교사 모드에서만 각 단계 끝에 표시됩니다.

- 켜기: 왼쪽 메뉴 **교사용 취합 → 교사 모드 켜기** → 코드 입력 (기본 코드 `명제교사`), 또는 주소 뒤에 `?teacher=명제교사` 를 붙여 접속
- 끄기: 같은 화면의 **교사 모드 끄기**, 또는 `?teacher=off`
- 코드는 `index.html` 안의 `TEACHER_CODE` 값을 바꾸면 됩니다. (브라우저별로 저장되므로 수업용 PC에서 한 번만 켜면 유지됩니다. 단, 소스에 코드가 들어 있으므로 강한 보안 장치는 아닙니다.)

## 기능

- 브라우저 자동 저장 (localStorage) — 같은 기기·브라우저에서 이어서 작업
- **저장 / 불러오기** — JSON 파일로 내려받아 다른 기기에서 이어서 작업, 교사 제출용
- **활동 기록** — 인쇄 / PDF 저장, Word(.docx) 다운로드, 텍스트(.txt)
- **교사용 취합** — 학생 JSON 파일을 여러 개 올려 진행 상황 표, 보고서 일괄 인쇄, CSV
- 수학 기호 팔레트 (≥ ≤ ≠ ² √ ¬ → ⇒ ⇔ ∀ ∃ ∈ ⊂ ∪ ∩ ∅ …)
- 규칙 기반 자동 점검 힌트 (예: p와 ¬p를 둘 다 참이라고 했을 때, 원명제와 대우의 참·거짓이 다를 때, 부등호를 부정하지 않았을 때 등)

## 배포 방법 (무료)

**방법 1 – 주소로 배포 (권장)**: 교실에 인터넷이 되므로 아래 GitHub Pages나 Netlify Drop에 올리고 주소(QR)를 학생에게 공유하면 됩니다. 모든 학생이 같은 주소를 쓰되 기록은 각자 브라우저에 저장됩니다.

**방법 1-2 – 파일 그대로 전달**: `index.html`을 학급 게시판·메신저로 보내면 학생이 더블클릭해서 바로 사용할 수도 있습니다.

**방법 2 – GitHub Pages**: 저장소를 만들고 `index.html`을 올린 뒤 Settings → Pages → Branch: main 을 선택하면 `https://<아이디>.github.io/<저장소>/` 주소가 생깁니다.

**방법 3 – Netlify Drop**: https://app.netlify.com/drop 에 이 폴더를 끌어다 놓으면 즉시 주소가 생깁니다.

## 수업 운영 팁

- 학생은 마지막에 **저장(JSON)** 과 **Word 또는 PDF** 두 가지를 제출하게 하면, JSON은 교사용 취합 화면에서 한꺼번에 볼 수 있고 문서는 평가 자료로 보관할 수 있습니다.
- 단계별 자동 힌트는 형식만 점검합니다. 내용 피드백은 정리표와 보고서를 보며 교사가 제공하는 것을 전제로 설계했습니다.
- 문항·문구 수정은 `index.html` 안의 `STEPS` 배열(각 단계의 `intro`, `draft`, `reveal`, `checklist`, `practice`, `quiz`)만 고치면 됩니다.
